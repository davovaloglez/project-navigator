# Investigaciones

Reportes de investigación y análisis (épica **Investigación**): spikes técnicos, evaluación de integraciones de terceros, comparativas de opciones y decisiones de arquitectura con sus trade-offs.

A diferencia de [user/](../user/) y [dev/](../dev/) —que documentan el producto **tal como existe**—, esta carpeta guarda el **razonamiento detrás de una decisión** en un momento dado. Son documentos con fecha; su contenido puede quedar desactualizado conforme cambia el ecosistema o el producto. Cada reporte indica su fecha y, cuando aplica, las fuentes verificadas.
